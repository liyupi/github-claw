### 1. Issue 自动化处理工作流
- 创建 `.github/workflows/issue-handler.yml`
- 功能：
  - 新 Issue 创建时自动回复确认评论，提示补充环境信息、复现步骤、期望行为等
  - 新 Issue 带 `bug` 标签时，自动分配给 Copilot coding agent
  - 已有 Issue 后续被添加 `bug` 标签时，也会自动分配 Copilot 并发通知评论
- 使用 `actions/github-script@v7`，无额外依赖
- 通过 CodeQL 安全扫描，无漏洞

## 决策记录
- 选择 `actions/github-script@v7` 而非 `gh` CLI：更灵活、可直接操作 GitHub API、不需要额外配置 token
- 使用 try/catch 包裹 Copilot 分配：确保即使 Copilot 未启用，工作流也不会失败
- 将作者介绍从简单的社区卡片扩展为独立板块：提供更丰富的信息，更好地展示鱼皮的背景和成就

1. **内容扩展的原则**：在扩展内容时，保持结构化和层次化很重要。将一个简短介绍扩展为 6 个维度的详细介绍，既丰富了内容，又保持了可读性。

2. **用户体验考虑**：添加导航链接让用户能够快速跳转到关心的内容，这是良好用户体验的体现。

3. **设计一致性**：复用现有的 CSS 类和设计模式，确保新内容与整体风格保持一致。
